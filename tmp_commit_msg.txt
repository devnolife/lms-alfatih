feat: phase 2 - group task board and daily deliverables

Adds collaborative group work to live class sessions: a kanban task
board and a "Hasil Hari Ini" deliverable panel, both real-time over the
existing SSE stream.

Schema (prisma db push):
- GroupTask (TaskStatus TODO/DOING/DONE) + GroupDeliverable
  (DeliverableType TEXT/LINK/CODE/IMAGE, ReviewStatus) + back-relations.

Server:
- src/lib/groupwork.ts: validation + caps (200 tasks / 100 deliverables,
  title 120, text 10k, URL 2k, http(s)-only links), race-safe guarded
  claim, display-name resolution, post-commit task:update/deliverable:update
  broadcasts.
- Routes: POST /tasks, PATCH|DELETE /tasks/[taskId], POST /deliverables,
  PATCH|DELETE /deliverables/[delId]. Snapshot now returns tasks +
  deliverables. All mutations scoped by sessionId.

Authorization:
- Any member creates/claims tasks; title edits limited to creator/claimer/
  teacher; teacher-only deliverable review; ENDED sessions lock student
  writes while teachers can still review/delete.

Client:
- useSessionStream tracks tasks + deliverables.
- TaskBoard (claim/move/release/delete) and DeliverablePanel (typed
  submissions, teacher review controls) wired into SessionRoom.

Verified: lint, build, and an end-to-end run (create/claim/move tasks,
race guard prevents claim-stealing, link validation rejects javascript:
URLs, teacher review, student review 403, ENDED 409 lock).
