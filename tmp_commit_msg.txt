feat(sessions): Phase 3 — multiplayer quiz arcade with live scoreboard

Add a real-time "Kuis Cepat Kelompok" to live class sessions: the teacher
starts a quiz round, students play an MCQ quiz locally and submit their score,
and everyone watches a live scoreboard update over SSE.

- schema: GameStatus/GameRound/GameScore (normalized score rows, PK
  [roundId,userId] to avoid JSON read-modify-write races on concurrent submits)
- src/lib/games.ts: GAME_CATALOG, teacher-only startRound (one OPEN round per
  session, auto-closes prior), submitScore (OPEN + belongs-to-session check,
  score clamped 0..max, idempotent monotonic-max upsert), teacher-only
  closeRound, getGameState + broadcastGame (game:update full-state event)
- routes: POST /game (start), POST /game/[roundId]/score, /close (rate-limited)
- snapshot + useSessionStream extended with game state and game:update case
- UI: client quizBank (kuis-output / kuis-rumpang), GamePanel with QuizRunner
  modal and medal scoreboard, wired into SessionRoom

Verified via e2e: student start 403, bad gameKey 400, score monotonic-max +
clamp, teacher close, score-after-close 409, live scoreboard streams via SSE.
Lint + production build clean.
